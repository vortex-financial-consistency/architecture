# Definition of Done (DoD)

Itens obrigatórios para considerar uma tarefa pronta:
- [ ] Código com cobertura de testes (mínimo X%)
- [ ] Testes unitários e de integração passing
- [ ] ArchUnit ou regras de arquitetura preservadas
- [ ] Documentação da API / fluxos atualizada
- [ ] Revisão de código aprovada (2 revisores)
- [ ] Pipeline CI verde e imagem Docker publicada (se aplicável)
